# Script Library

This is the dedicated home for your own MySQL and MariaDB automation scripts.

Add your `.sql`, `.sh`, `.ps1` or other reviewed script files under `content/mysql/scripts/`, then link to them from this page. For each script, document its purpose, prerequisites, execution account, parameters, expected output, validation, rollback and safety considerations.

No script content has been invented here; this page is a starter location for your material.
