# Logo asset integration — V1.5

The following SVG files supplied by the project owner are used directly as local assets:

| Technology | Supplied file | Project asset |
|---|---|---|
| Oracle Database | Oracle_logo.svg | oracle-wordmark.svg |
| MySQL | mysql-logo-svgrepo-com.svg | mysql-wordmark.svg |
| Microsoft SQL Server | microsoft-sql-server-light.svg | sqlserver-wordmark.svg |
| AWS | Amazon_Web_Services_Logo.svg | aws-wordmark.svg |
| Microsoft Azure | Microsoft_Azure.svg | azure-mark.svg |
| Oracle Cloud | oracle-cloud.svg | oracle-cloud-mark.svg |
| Python | Python-logo-notext.svg | python-mark.svg |
| PowerShell | powershell.svg | powershell-mark.svg |

The AWS wordmark's dark navy lettering was changed to a light neutral tone for contrast on the existing dark dashboard; its orange smile remains unchanged. The MySQL blue was brightened slightly for legibility. The Oracle Cloud SVG viewBox was cropped to its visible mark so it scales correctly.

All logo assets remain transparent SVGs. No white logo tiles or white card backgrounds were added, preserving the approved navy dashboard theme. Technology cards render one logo asset only, followed by the existing progress bar and topic count; duplicate text labels beneath logos were removed.

Other technology icons continue to use the existing bundled SVG assets. Shell currently uses the existing Simple Icons fallback.
