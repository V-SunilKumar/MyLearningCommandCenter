# My Learning Command Center — V1.7

## Progress bar correction
This release replaces the fragile technology-card progress fill with a positioned fill element whose width and colour are driven by the technology's calculated percentage and configured brand accent.

## Start
1. Extract this ZIP into a new folder.
2. Close any older dashboard command windows.
3. Double-click `start-dashboard.bat`.
4. Open `http://localhost:8771`.

This version uses a new local port and cache-busted CSS/JavaScript URLs to avoid accidentally viewing an older running copy.
