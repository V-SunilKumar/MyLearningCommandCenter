# DBA & Cloud Learning Command Center

GitHub Pages-ready static dashboard.

## Deploy
1. Upload the contents of this ZIP to the root of your GitHub repository.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your default branch (usually `main`) and folder `/ (root)`, then save.

Every technology card is clickable and opens its respective roadmap. Progress is stored locally in the browser using `localStorage`.
