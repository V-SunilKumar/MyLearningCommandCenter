# DBA & Cloud Learning Command Center — GitHub Prototype v1

A static GitHub Pages-ready prototype based on the agreed navigation model:

Dashboard → Oracle Roadmap → Learning Objective → One complete Knowledge Page → Progress

## Included sample
Oracle DBA → Storage Management → Tablespace Management → What is a Tablespace?

The objective page contains Notes, My Notes, KT Notes, Commands, Hands-on Lab, Production Scenario, Interview Questions and Quick Revision in one vertically scrollable page.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Create a GitHub repository, upload these files to the repository root, and enable GitHub Pages from the repository Pages settings using the main branch/root folder.

## Prototype persistence
This v1 saves personal objective status, notes and lab checks in browser localStorage. This phase is intentionally for visual/UX validation before adding authenticated cross-device persistence.
